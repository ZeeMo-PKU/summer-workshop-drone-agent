# Multi-round vision evidence: 2026-08-06

This directory contains public test images collected while developing the
isolated multi-round controller. The project owner approved these images for
the public project report.

## Contents

- `captures/`: one front-camera scene image and one answer-layout image from a
  flow run.
- `ground-camera-probe/`: five front-camera ground probes used to check camera
  availability and framing.
- `qwen-benchmark/`: twelve Qwen input images in four groups: aircraft, license
  plates, oil tanks, and vehicles.
- `SHA256SUMS`: hashes for all 19 JPEG files.

These images are vision evidence only. This directory does not claim that an
end-to-end real-flight run succeeded, and it intentionally excludes credentials,
runtime environment files, binaries, and unrelated server logs.
