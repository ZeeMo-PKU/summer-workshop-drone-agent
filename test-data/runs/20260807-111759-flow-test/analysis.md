# 便携场地仿真测试：首次校准失败

- 运行编号：`20260807-111759`
- 环境：`CFG_FLIGHTSIM=1`
- 任务高度：`7.0 m`
- 安全范围：水平半径 `20 m`，相对高度上限 `10 m`
- 结论：未触发 B 区，流程中止后安全返航；本轮不属于完整闭环通过。

## 观察结果

1. 程序接收 `MATCH_STARTED`，闭合夹爪并起飞至 7 米。
2. 程序认为已到达 B 场景区并稳定悬停 3 秒，但裁判监控中的位置约为 `x=0, z=5.52`，没有进入 B 区。
3. 由于监控系统仍使用 `fieldRotationDegrees=0`，其场地坐标轴与程序按机头建立的场地坐标轴相差 90 度。
4. 本轮未收到场景触发、题目或答题事件，也没有生成照片。
5. 测试人员结束隔离程序后，程序发送一次 `returnToAnyPosition(start, 7.0m)`。外层测试超时使日志在落地确认前结束，但飞控继续自主降落；随后只读状态确认 `STANDBY`、`armed=false`、高度 0、无控制进程。

## 额外缺陷

返航阶段遥测最高达到 `9.994 m`。虽然未超过本次 10 米安全上限，但明显高于 7 米任务高度，说明 `returnToAnyPosition` 会进入飞控自身的返航高度策略。

## 后续处理

第二轮前使用正式校准脚本把监控系统旋转设为 `-90` 度。该调整只修改本地监控配置，没有修改无人机控制源码。

`SERVER_SHA256SUMS` 是服务器原始运行目录的完整清单；`PUBLIC_SHA256SUMS` 是本公开归档副本的清单。
