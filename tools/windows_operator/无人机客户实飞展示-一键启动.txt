无人机客户实飞展示（一条命令）
==============================

用途：
把无人机带到新的室外展示场地后，以摆放位置和当前机头方向为基准，自动完成：
切换实飞模式 -> 起飞至 3 米 -> 悬停拍照 -> 飞正方形并转弯 -> 回到起点 -> 降落。

确认现场具备起飞条件后，在 Windows CMD 中完整复制下面这一行并按回车：

python "%USERPROFILE%\Desktop\无人机CMD控制\drone_operator.py" demo-real

运行后会立即开始实飞，不需要裁判系统，不需要再输入第二条命令。

启动前必须满足：
1. 飞机已放平、落地待机且未解锁。
2. 起飞点周围水平 20 米、上方 20 米内无人员和障碍物。
3. 电池能够完成整段航线，吊舱已正确安装。
4. RTK 状态和卫星数量通过程序检查。
5. 没有其他比赛程序或测试程序正在控制飞机。
6. 场地允许飞行，不属于禁飞区，也不在人群或道路上方。

这是一条会让实体无人机立即起飞的命令。程序会以每次启动时的位置动态建立
坐标，不绑定旧比赛场地；但“更换场地可用”不代表可以绕过当地法规、厂家
地理围栏、禁飞区或现场净空要求。

如需停止，另开一个 CMD 窗口运行：
python "%USERPROFILE%\Desktop\无人机CMD控制\drone_operator.py" stop-test
